VIVEK ATTENDANCE TRACKER

This is a mobile-friendly installable web app package (PWA), not a compiled APK.

To install on Android:
1. Extract the ZIP.
2. Upload index.html, manifest.json and service-worker.js to a free HTTPS host such as GitHub Pages.
3. Open the hosted site in Chrome.
4. Tap Chrome menu (⋮) > Add to Home screen / Install app.

Daily use: choose Present or Absent for each subject with a class; leave No class for subjects without a class; tap Save attendance. Edit counts lets you correct starting values. Export backup saves current data as JSON.

The app cannot connect to your college portal automatically. Data is stored in this browser on this phone. Lab/remedial rules may differ, so enter the values used by your college.
